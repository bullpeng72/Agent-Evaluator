1. 개요 — 25개 지표 전체 구조

🎯 Agent Evaluator 3계층 아키텍처

총 25개 지표로 구성된 프로덕션급 AI 에이전트 평가 프레임워크

  • Layer 1 Foundation: 6개 — 외부 의존성 없음, 무료
  • Layer 2 Agentic: 10개 (에이전틱 5 + 보안 5) — 외부 의존성 없음, 무료
  • Layer 3 Hybrid: 9개 (DeepEval 5 + Ragas 4) — 유료 (OpenAI API), 05_hybrid_metrics.py로 실제 API 커버
Layer카테고리지표개수비용
Layer 1 Foundation TCR, Accuracy, Hallucination, Response Quality, Latency, Token Economy 6개 무료
Layer 2 Agentic Tool Call Efficiency, Retry & Error Recovery, Tool Selection, Agent Coordination, Workflow Execution 5개 무료
Security Input Sanitization, Output Leakage, Tool Authorization, Privilege Escalation, Tool Chain Attack 5개 무료
Layer 3 Hybrid (DeepEval + Ragas) G-Eval, Hallucination(DE), Toxicity, Bias, Answer Relevancy(DE) / Faithfulness, Context Precision, Context Recall, Answer Relevancy(Ragas) 9개 유료

⚠️ Layer 3 사용 시 주의사항

5. 핵심 API — PerformanceMonitor

Import:

from agent_evaluator import PerformanceMonitor, TaskResult

초기화 플래그:

  • enable_hallucination_detection=True — 환각 탐지 활성화 (기본 False)
  • enable_security_metrics=True — 보안 트래커 5개 활성화 (기본 False)
  • pricing={"input": 0.00015, "output": 0.0006} — 토큰 비용 (per 1K)
  • output_dir="results/" — 결과 저장 디렉토리

record_task() 주요 파라미터:

  • task_result — TaskResult 객체
  • ground_truth — 정답 (Accuracy 평가용)
  • context — 컨텍스트 문자열 (Hallucination 탐지용)
  • request — 입력 요청 텍스트
  • response — 에이전트 응답 텍스트
  • expected_elements — 예상 포함 요소 목록 (Quality 평가용)

내장 트래커 접근:

  • monitor.tcr_tracker, monitor.accuracy_evaluator, monitor.hallucination_detector
  • monitor.quality_evaluator, monitor.latency_tracker, monitor.token_tracker
  • monitor.tool_analyzer, monitor.retry_tracker, monitor.tool_selection_tracker
  • monitor.agent_coordination_tracker, monitor.workflow_tracker
  • monitor.input_sanitizer, monitor.output_leakage_detector, monitor.tool_authorizer
  • monitor.privilege_escalation_detector, monitor.tool_chain_attack_detector

📝 보안 트래커 직접 호출 패턴

보안 트래커는 record_task()를 통해 자동 호출되지 않으며 별도로 직접 호출해야 합니다:

# Layer 2 Security — 입출력 및 도구 권한 검사
monitor.input_sanitizer.evaluate_input(task_id, input_text)
monitor.output_leakage_detector.detect_leakage(task_id, output_text)
monitor.tool_authorizer.track_tool_call(task_id, tool_name, args)

# Layer 2 Security — 권한 상승 / 체인 공격 분석
monitor.privilege_escalation_detector.analyze_privilege_chain(task_id, tool_calls_list)
monitor.tool_chain_attack_detector.analyze_tool_chain(task_id, tool_sequence_list)

📝 Quality Evaluator 직접 호출 패턴

ResponseQualityEvaluator도 record_task() 외에 별도 호출이 필요합니다:

monitor.quality_evaluator.evaluate_response(
    task_id=task_id,
    request=request_text,
    response=response_text,
    ground_truth=ground_truth,
    expected_elements=expected_list,
)

📄 02_performance_metrics.py — 성능 지표

지표API 호출 방식비고
TCR record_task(task) → tcr_tracker.calculate_tcr() full/partial/failure 분류
Latency (p50/p95/p99) record_task(execution_time=...) → latency_tracker SLA 검사 포함 (check_sla_compliance())

Retry & Correction TaskResult(attempts=N) attempts > 1이면 retry_tracker 자동 등록
Accuracy monitor.accuracy_evaluator.add_evaluation(task_id, ground_truth, response, task_type) 9가지 태스크 유형별 ground_truth 지정 — 직접 호출
Response Quality (5-dim) monitor.quality_evaluator.evaluate_response(task_id, response, request, expected_elements, ground_truth) 태스크 유형별 expected_elements 지정 — 직접 호출

📄 03_agentic_metrics.py — 에이전틱 지표

8. 빠른 참조 — API 패턴

🚀 기본 평가 패턴 (Layer 1)

from agent_evaluator import PerformanceMonitor, TaskResult

monitor = PerformanceMonitor(
    enable_hallucination_detection=True,
    pricing={"input": 0.00015, "output": 0.0006},
    output_dir="results/",
)

task = TaskResult(
    task_id="task_001", task_type="qa",
    success=True, completion_score=0.95, accuracy_score=0.88,
    execution_time=1.23,
    tokens_used={"input": 150, "output": 80, "total": 230},
    tool_calls=[], attempts=1, errors=[], timestamp=datetime.now(),
)

monitor.record_task(task, ground_truth="서울", context="...", request="...", response="...")
monitor.quality_evaluator.evaluate_response(task_id="task_001", ...)

report = monitor.generate_report()
monitor.save_to_file("my_eval.json")
