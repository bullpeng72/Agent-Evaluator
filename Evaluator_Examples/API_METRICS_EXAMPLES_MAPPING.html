1. 개요 - 25개 메트릭 전체 구조

🎯 Agent Evaluator 3계층 아키텍처

총 25개 메트릭으로 구성된 포괄적인 AI 에이전트 평가 프레임워크

  • Layer 1: 10개 Basic (7) + Security (3) - 완전 무료, API 키 불필요
  • Layer 2: 6개 Agentic (4) + Security (2) - 완전 무료, 멀티 에이전트 전용
  • Layer 3: 9개 DeepEval (5) + Ragas (4) - 유료, OpenAI API 필요

Layer 2 Agentic Metrics

4. Layer 3 메트릭 (9개) - DeepEval + Ragas

⚠️ Layer 3 사용 시 주의사항

  • OpenAI API 키 필수: .env 파일 또는 환경 변수 설정
  • 비용 발생: $0.01-0.02/task (gpt-4o-mini 기준)

5. 핵심 API - PerformanceMonitor & HybridMonitor

🎯 PerformanceMonitor (Layer 1 + 2)

Import:

from agent_evaluator import PerformanceMonitor, create_taskresult, TaskResult, TaskType

주요 메서드:

  • __init__(enable_hallucination_detection=True, enable_security_metrics=False)
  • record_task(task: TaskResult) - Task 기록
  • generate_report() -> Dict - 평가 리포트 생성
  • save_to_file(filename: str) - JSON 파일 저장
  • evaluate_with_golden_dataset(agent_fn, dataset_path, enable_layer2_metrics=False)

내장 Trackers:

  • monitor.tcr_tracker - TaskCompletionTracker
  • monitor.accuracy_evaluator - AccuracyEvaluator
  • monitor.hallucination_detector - HallucinationDetector
  • monitor.quality_evaluator - ResponseQualityEvaluator
  • monitor.latency_tracker - LatencyTracker
  • monitor.token_tracker - TokenEconomyTracker
  • monitor.tool_analyzer - ToolCallAnalyzer
  • monitor.tool_selection_tracker - ToolSelectionTracker
  • monitor.agent_coordination_tracker - AgentCoordinationTracker
  • monitor.workflow_tracker - WorkflowExecutionTracker
  • monitor.input_sanitizer - InputSanitizationTracker (v0.5.0+)
  • monitor.output_leakage_detector - OutputLeakageDetector (v0.5.0+)
  • monitor.tool_authorizer - ToolAuthorizationTracker (v0.5.0+)
  • monitor.privilege_escalation_detector - PrivilegeEscalationDetector (v0.5.0+)
  • monitor.tool_chain_attack_detector - ToolChainAttackDetector (v0.5.0+)

🚀 HybridPerformanceMonitor (Layer 1 + 2 + 3)

Import:

from agent_evaluator.core.hybrid_monitor import HybridPerformanceMonitor

주요 메서드:

  • __init__(use_deepeval=True, use_ragas=True, deepeval_model="gpt-4o-mini")
  • record_task(task, enable_advanced_metrics=True, input_text=None, output_text=None, expected_output=None, retrieved_context=None, quality_criteria=None)
  • generate_hybrid_report() -> Dict - Layer 1+2+3 통합 리포트

Layer 3 어댑터:

  • monitor.deepeval_adapter - DeepEvalAdapter (5개 메트릭)
  • monitor.ragas_adapter - RagasAdapter (4개 메트릭)

📝 TaskResult 생성

Helper 함수:

create_taskresult(task_id, task_type, question, response, ground_truth=None, context=None)

직접 생성:

TaskResult(task_id, task_type, question, response, completion_score, accuracy_score, ...)

TaskResult 주요 필드:

  • expected_tools: List[str] - Tool Selection 평가용
  • chain_steps: List[Dict] - LangChain 워크플로우용
  • graph_traversal: Dict - LangGraph 워크플로우용
  • agent_interactions: List[Dict] - Agent 협업 추적용
  • conversation_turns: List[Dict] - 대화 추적용
  • state_transitions: List[Dict] - 상태 전이 추적용

⚠️ RAG/Ragas 평가 시 주의

retrieved_context는 TaskResult 필드가 아니라 HybridPerformanceMonitor.record_task() 메서드의 매개변수로 전달합니다:

monitor.record_task(task, retrieved_context=[doc1, doc2, ...])

6. 고급 분석 API (7개) - v0.5.0+ NEW

🎯 개요

v0.5.0+에서 추가된 7개의 고급 분석 API는 기본 메트릭을 더 깊이 분석할 수 있는 강력한 도구입니다.

특징:

  • ✅ 완전 무료 (Layer 1, 2 메트릭 기반)
  • ✅ 유형별, 차원별, 모델별 상세 분석
  • ✅ 병목 지점, 패턴, 최적화 제안 자동 생성
  • ✅ Level 2 Example 08에서 전체 데모 제공
# API 메서드 Tracker 제공 정보 예제
1 get_hallucination_by_type() HallucinationDetector 환각 유형별 통계 (숫자, 시간, 주장 오류) L2-08
2 get_quality_by_dimension() ResponseQualityEvaluator 5개 품질 차원별 점수 분포 (관련성, 완전성, 정확성, 명확성, 유용성) L2-08
3 get_latency_by_type() LatencyTracker Task 타입별 지연시간 (평균, P95, P99) L2-08
4 get_cost_breakdown_by_model() TokenEconomyTracker 모델별 비용, 토큰 사용량, 작업당 평균 L2-08
5 get_tool_usage_patterns() ToolCallAnalyzer 도구 사용 패턴 (중복, 실패, 효율성 분포) L2-08
6 get_critical_path_analysis() WorkflowExecutionTracker 병목 지점, 병렬화 기회, 최적화 권장사항 L2-08
7 get_interaction_patterns() AgentCoordinationTracker 협업 패턴 (Hub, Chain, Mesh), 역할 분석 L2-08

💡 사용 예시

# 1. 환각 유형별 분석
breakdown = evaluator.hallucination_detector.get_hallucination_by_type()
print(f"숫자 오류: {breakdown['numerical_errors']}")

# 2. 품질 차원별 분석
quality = evaluator.quality_evaluator.get_quality_by_dimension()
print(f"Relevance: {quality['relevance']:.2f}/5.0")

# 3. Task 타입별 지연시간
latency = evaluator.latency_tracker.get_latency_by_type()
print(f"QA P95: {latency['qa']['p95']:.3f}s")

# 4. 모델별 비용 분석
cost = evaluator.token_tracker.get_cost_breakdown_by_model()
print(f"gpt-4 비용: ${cost['gpt-4']['total_cost']:.4f}")

# 5. 도구 사용 패턴
patterns = evaluator.tool_analyzer.get_tool_usage_patterns()
print(f"중복 호출: {patterns['redundancy_impact']['total_redundant']}")

# 6. Critical Path 분석
analysis = evaluator.workflow_tracker.get_critical_path_analysis()
print(f"병목 지점: {analysis['bottlenecks'][0]['step_name']}")

# 7. 상호작용 패턴
patterns = evaluator.agent_coordination_tracker.get_interaction_patterns()
print(f"패턴 유형: {patterns['pattern_type']}")

10. 예제에서 다루지 않는 고급 기능

✅ v0.5.0 업데이트: 대부분의 고급 기능이 예제에서 완전히 다루어집니다!

새로 추가된 예제 커버리지:

  • ✅ Helper 함수 (5개) → Level 1 Example 09에서 종합 다룸 (Demo, JSON 미생성)
  • ✅ state_transitions 필드 → Level 1 Example 10에서 FSM 워크플로우 다룸 (Demo, JSON 미생성)
  • ✅ 고급 분석 API (7개) → Level 2 Example 08에서 전체 다룸 (Evaluation, JSON 생성)
  • ✅ conversation_turns, state_transitions, agent_interactions → Level 1 Example 07에서 다룸 (Demo, JSON 미생성)

현재 예제 커버리지:

  • 📊 메트릭 커버리지: 25개 메트릭 중 16개 직접 다룸 (64%)
  • 🔧 API 커버리지: 핵심 API 및 고급 API 7개 완전 커버
  • 🛠️ Helper 커버리지: 5개 Helper 함수 모두 커버

📈 PerformanceMonitor - 고급 설정

예제에서 다루지 않는 초기화 옵션:

  • enable_cost_tracking=True - 비용 추적 활성화 (기본값 True, 예제에서는 명시 안함)
  • enable_latency_tracking=True - 지연시간 추적 (기본값 True)
  • custom_thresholds: Dict - 커스텀 임계값 설정 (예제 04에서 부분 다룸)
  • enable_layer2_by_default=False - Layer 2 메트릭 기본 활성화 여부

🧪 HybridPerformanceMonitor - 고급 설정

예제에서 다루지 않는 초기화 옵션:

  • deepeval_threshold: float - DeepEval 메트릭 Pass/Fail 임계값 설정
  • ragas_threshold: float - Ragas 메트릭 임계값 설정
  • use_langsmith=False - LangSmith 통합 (실험적)
  • cache_evaluations=True - 평가 결과 캐싱으로 비용 절감
  • parallel_evaluation=False - 병렬 평가 (빠르지만 비용 증가)
