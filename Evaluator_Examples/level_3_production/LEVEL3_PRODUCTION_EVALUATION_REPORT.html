Example 01: CrewAI Framework Integration

📚 학습 목표

CrewAI는 멀티 에이전트 협업 프레임워크로, 역할 기반 에이전트(Researcher, Writer, Editor 등)가 순차적 또는 병렬로 협업하여 복잡한 작업을 수행합니다. Agent Evaluator와 통합하여 Layer 1 + Layer 2 메트릭을 자동 수집하고 성능을 모니터링합니다.

🤖 CrewAI 핵심 구조

  • Agent: 역할, 목표, 배경 스토리를 가진 독립적 에이전트
  • Task: 각 Agent가 수행할 작업 정의
  • Tool: Agent가 사용할 수 있는 도구 (검색, 계산기 등)
  • Crew: Agent와 Task를 조합하여 워크플로우 실행
  • Process: 순차(Sequential) 또는 계층적(Hierarchical) 실행

✅ 모범 사례

  • Error Handling: try-except로 실패 케이스도 기록

  • A/B 테스트: 다른 Agent 구성 비교 (2 agents vs 3 agents)

💡 Stratified Sampling이란?

TaskType별로 균등하게 샘플링하여 각 그룹의 특성을 반영합니다. 예: QA 50개 → 10개 Layer 3 (20%), Code 30개 → 6개 Layer 3 (20%), Creative 20개 → 4개 Layer 3 (20%)

💻 실전 구현 코드

# 비용 최적화 구현 예제 from agent_evaluator import PerformanceMonitor from agent_evaluator.core.hybrid_monitor import HybridPerformanceMonitor import random # Layer 1 Monitor (모든 Task) monitor_l1 = PerformanceMonitor() # Layer 3 Monitor (샘플링용) monitor_l3 = HybridPerformanceMonitor( use_deepeval=True, use_ragas=True ) # 평가 루프 for i, task_data in enumerate(tasks): # Layer 1: 모든 Task task = create_task(task_data) monitor_l1.record_task(task) # Layer 3: 20% Stratified Sampling if should_evaluate_layer3(i, task_data): monitor_l3.record_task(task, context=..., response=...) def should_evaluate_layer3(index, task_data): # Strategy 4: Stratified Sampling (20%) return (index % 5) == 0 # 매 5번째

✅ Best Practice

  • 단계별 접근: Phase 1 (Layer 1만) → Phase 2 (10% 테스트) → Phase 3 (20% Stratified)
  • 모니터링: 매월 비용 추적 및 정확도 변화 관찰
  • 임계값 설정: Layer 1 (TCR ≥ 85%), Layer 3 샘플 (TCR ≥ 95%)
  • 자동화: CI/CD 통합, 자동 샘플링, 비용 알림 설정
  • 정기 리뷰: 분기별 전략 재평가 및 샘플링 비율 최적화

Example 06: Security Production Monitoring

📚 학습 목표

프로덕션 환경에서의 실시간 보안 모니터링을 구현합니다. Layer 1 (Native) + Layer 2 (Agentic) 보안 메트릭을 통합하여 복합적인 보안 위협을 탐지하고, 자동 알림 및 규정 준수 모니터링을 수행합니다.

🛡️ Production Security 핵심 구성 (v0.5.0+)

  • Layer 1 Security (Native - 3개): Input Sanitization, Output Leakage Detection, Tool Authorization
  • Layer 2 Security (Agentic - 2개): Privilege Escalation Detection, Attack Pattern Detection
  • 총 5개 보안 메트릭: 완전 자동 수집, API 키 불필요
  • Security Risk Score: 종합 위험도 점수 계산 (0-100)
  • Compliance Monitoring: 규정 준수 자동 검사 (GDPR, SOC 2)
  • Alert System: Critical 위협 시 즉시 알림 (Slack, Email)

🎯 Framework 선택 가이드

📌 Use CrewAI when:

  • 역할 기반 Agent가 명확할 때 (Researcher, Writer, Editor 등)
  • 빠른 프로토타이핑이 필요할 때
  • 실행 시간이 중요하지 않을 때 (배치 처리)
  • 협업 워크플로우가 주요 요구사항일 때

📌 Use LangChain when:

  • RAG 시스템을 구축할 때
  • 다양한 LLM Provider를 통합할 때
  • 병렬 처리로 성능을 최적화할 때
  • LCEL로 체인을 표준화하고 싶을 때

📌 Use LangGraph when:

  • 복잡한 상태 전이가 필요할 때
  • 조건부 분기와 루프가 많을 때
  • Multi-Agent를 세밀하게 조율해야 할 때
  • 워크플로우 시각화가 중요할 때
