# ============================================================================
# Installation Instructions
# ============================================================================
#
# 1. Install agent_evaluator package first:
#    cd /path/to/your/Examples
#    pip install -e .
#
# 2. Install dashboard dependencies:
#    cd Dashboard
#    pip install -r requirements.txt
#
# 3. Run the dashboard:
#    streamlit run app.py
#    # or
#    streamlit run streamlit_dashboard.py
#
# 4. Optional: Install framework integrations
#    pip install pyautogen langchain langchain-core langgraph crewai
#
# 5. Optional: Install advanced metrics
#    pip install deepeval ragas
#
# ============================================================================
# Dashboard Features
# ============================================================================
#
# Main Dashboard (streamlit_dashboard.py):
#   - 9 tabs: Overview, Core Metrics, Performance, Agentic AI, Advanced,
#             Insights, Test 투명성, 지표 설명, Export
#   - Supports Layer 1 (native), Layer 2 (agentic), Layer 3 (advanced) metrics
#   - Interactive visualizations with Plotly
#   - Export to HTML, CSV, JSON
#
# Data Editor (dashboard_data_editor.py):
#   - Interactive data table editing
#   - Test transparency visualization
#   - Annotation UI
#   - Audit log viewer
#
# Entry Point (app.py):
#   - Zero-configuration setup
#   - Automatic path resolution
#   - Import validation
#
# ============================================================================
# File Structure
# ============================================================================
#
# Dashboard/
# ├── app.py                      # Entry point
# ├── streamlit_dashboard.py      # Main dashboard
# ├── dashboard_data_editor.py    # Data editor UI
# ├── data_editor_manager.py      # Data editor logic
# ├── requirements.txt            # This file
# ├── data/                       # Evaluation results (JSON)
# ├── pages/
# │   └── 데이터편집.py           # Additional page
# └── utils/
#     ├── enhanced_recommendations.py  # Advanced recommendations
#     └── merge_evaluation_results.py  # Result merging
#
# ============================================================================
# Troubleshooting
# ============================================================================
#
# Issue: ModuleNotFoundError: No module named 'agent_evaluator'
# Solution: Install agent_evaluator package first
#   cd /path/to/your/Examples
#   pip install -e .
#
# Issue: Dashboard shows "No data files found"
# Solution: Run examples first to generate evaluation results
#   cd level_1_foundation
#   python 01_quickstart.py
#   # Results will be saved to Dashboard/data/
#
# Issue: ImportError with framework integrations
# Solution: Install optional dependencies as needed
#   pip install pyautogen langchain langgraph crewai
#
