# 서문: AI 에이전트 평가, 왜 지금인가

---

## 이 책이 필요한 이유

소프트웨어 세계는 지금 조용하고도 근본적인 전환점을 맞이하고 있습니다. 기존 소프트웨어는 결정론적입니다. 함수에 동일한 입력을 넣으면 항상 동일한 출력이 나옵니다. 테스트도 그 원칙 위에 세워졌습니다. `assert result == expected` 한 줄이면 충분했습니다.

AI 에이전트는 다릅니다. 에이전트는 도구를 선택하고, 외부 API를 호출하고, 여러 단계에 걸쳐 스스로 계획을 수정합니다. 같은 질문에도 매번 다른 경로로 답에 도달합니다. 때로는 환각(hallucination)으로 틀린 정보를 자신감 있게 전달하고, 때로는 허가되지 않은 도구를 실행하거나 민감한 데이터를 출력에 포함시키기도 합니다. `assert`는 이 복잡성을 포착하지 못합니다.

이 책은 그 간극을 메우기 위해 쓰였습니다. AI 에이전트를 프로덕션에 배포하기 전에 **무엇을**, **어떻게** 평가해야 하는지를 실무 중심으로 다룹니다. 이론보다 코드, 개념보다 실제 동작하는 예시를 우선합니다.

## 실습 환경 안내

이 책의 모든 코드 예시는 **Python 3.8 이상** 환경에서 실행됩니다. 실습을 위해 다음 환경이 필요합니다.

```bash
# 기본 설치 (Layer 1+2 지표 + 대시보드)
pip install "agent-evaluator[all]"

# 실습 확인
agent-eval --version
# → agent-evaluator 0.7.5
```

LLM API를 사용하는 예시에서는 OpenAI 또는 Anthropic API 키가 필요합니다. 프로젝트 루트에 `.env` 파일을 만들고 키를 설정하면 됩니다.

```bash
# .env
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
```

API 키 없이도 Layer 1과 Layer 2의 25개 지표 중 16개는 완전히 동작합니다. LLM 없이 알고리즘으로 계산하기 때문입니다.

## Agent-Evaluator SDK 소개

이 책에서 사용하는 **Agent-Evaluator**는 AI 에이전트 평가를 위해 설계된 오픈소스 Python SDK입니다.

- **버전**: v0.7.5 (Beta)
- **라이선스**: MIT
- **지원 Python**: 3.8 ~ 3.13

핵심 설계 원칙은 세 가지입니다. 첫째, **외부 의존성 없는 네이티브 평가**입니다. 25개 지표 중 16개는 OpenAI나 Anthropic API 없이 로컬에서 즉시 계산됩니다. 둘째, **데코레이터 한 줄**로 평가를 시작할 수 있는 최소 마찰 설계입니다. 셋째, **3-레이어 구조**로 기본 지표부터 외부 평가 도구 통합까지 점진적으로 확장할 수 있습니다.

25개 성능 지표는 세 개의 레이어로 구성됩니다. Layer 1은 Task Completion Rate, Accuracy, Hallucination Detection 등 6개의 기반 지표로, 별도 설정 없이 항상 자동으로 활성화됩니다. Layer 2는 Tool 선택 정확도, 보안 위협 탐지 등 10개의 에이전틱 전용 지표로, 필요에 따라 활성화합니다. Layer 3는 DeepEval, Ragas, LangSmith 등 외부 평가 도구와 연동하는 하이브리드 레이어입니다.

## 각 파트 간략 소개

**Part I — 기초**: AI 에이전트 평가의 개념, SDK 설치와 첫 실행, 3-레이어 구조 이해. 이 책의 출발점입니다.

**Part II — 25개 지표 심화**: 각 지표의 계산 방식, 임계값 설정, 실무 해석 방법을 다룹니다. 지표별 레퍼런스로 활용할 수 있습니다.

**Part III — 프레임워크 통합**: LangChain, LangGraph, CrewAI, AutoGen 등 21개 프레임워크와 Agent-Evaluator를 연결하는 실전 예시를 제공합니다.

**Part IV — 운영과 자동화**: CI/CD 품질 게이팅, Phoenix 실시간 모니터링, 대시보드 운영, 골든 데이터셋 관리를 다룹니다. 에이전트를 지속적으로 운영하는 팀을 위한 파트입니다.

AI 에이전트는 더 이상 실험실의 프로토타입이 아닙니다. 지금 이 순간에도 수많은 서비스의 핵심 로직을 담당하고 있습니다. 평가 없이 배포된 에이전트는 언제 어떤 방식으로 실패할지 알 수 없습니다. 이 책이 그 불확실성을 측정 가능한 것으로 바꾸는 데 도움이 되기를 바랍니다.
