# Agent Evaluator — Web Dashboard 설계 기획서

**버전:** 1.0
**대상:** `agent-eval serve` CLI 명령으로 실행되는 FastAPI + 순수 HTML/JS 웹 UI
**참조:** 기존 Streamlit 대시보드의 전체 기능 + reveal.js 프레젠테이션 모드

---

## 1. 설계 원칙

### 1-1. 왜 Streamlit을 대체하는가

| 항목 | Streamlit 현황 | 새 Web UI |
|------|---------------|-----------|
| 배포 방법 | `streamlit run` (별도 설치) | `agent-eval serve` (pip 패키지 포함) |
| 공유 | 링크 공유 불가 (로컬 전용) | HTTP URL 그대로 공유 |
| 프레젠테이션 | 불가 | reveal.js 슬라이드 모드 내장 |
| 실시간 업데이트 | 없음 (수동 새로고침) | SSE 스트리밍 자동 갱신 |
| 외부 의존성 | streamlit, plotly, pandas 필수 | FastAPI + 순수 HTML/CSS/JS (CDN) |
| 커스텀 스타일 | 제한적 | 완전 제어 가능 |

### 1-2. 기술 스택

```
Backend  : FastAPI (uvicorn) — agent_evaluator 패키지에 포함
Frontend : 순수 HTML5 + CSS3 + Vanilla JS (ES2020)
           ├── Chart.js 4.x     (차트 — CDN)
           ├── reveal.js 5.x    (슬라이드 모드 — CDN)
           ├── Alpine.js 3.x    (반응형 UI — CDN)
           └── Tabulator 6.x    (인터랙티브 테이블 — CDN)
데이터    : JSON (agent_evaluator 출력 파일 그대로 사용)
통신      : REST API + Server-Sent Events (SSE)
```

> **CDN 의존**: 외부 JS 라이브러리는 모두 CDN에서 로드.
> `--offline` 플래그 지정 시 로컬 번들 사용 (선택적 구현).

## 2. CLI 명령 명세

### 2-1. `agent-eval serve`

```bash
agent-eval serve [OPTIONS] [RESULTS_DIR]

Arguments:
  RESULTS_DIR   평가 결과 디렉토리 (기본: ./results)
                JSON 파일을 재귀 탐색한다.

Options:
  --host TEXT       바인딩 호스트    [기본: 127.0.0.1]
  --port INTEGER    포트 번호        [기본: 8765]
  --open            브라우저 자동 오픈
  --watch           결과 디렉토리 파일 변경 감시 (핫 리로드)
  --offline         CDN 대신 번들 JS 사용
  --slide           시작 화면을 reveal.js 슬라이드로 설정
  --title TEXT      대시보드 제목    [기본: "Agent Evaluator Dashboard"]
  --share           외부 접근 허용 (host=0.0.0.0 단축키)
```

**사용 예시:**
```bash
# 기본 실행
agent-eval serve

# 특정 디렉토리 + 브라우저 자동 오픈
agent-eval serve ./my_results --open

# 파일 감시 + 팀 공유
agent-eval serve --watch --share --port 8080

# CI 결과를 슬라이드로 바로 열기
agent-eval serve ./ci_results --slide --open
```

**실행 시 출력:**
```
  Agent Evaluator Dashboard v0.5.2
  ─────────────────────────────────
  📁  Results dir : ./results  (3개 파일 발견)
  🌐  Dashboard   : http://127.0.0.1:8765
  📊  Slides      : http://127.0.0.1:8765/slides
  📡  API         : http://127.0.0.1:8765/api
  🔄  Watch mode  : ON

  Ctrl+C 로 종료
```

## 3. 전체 아키텍처

```
agent_evaluator/
├── serve/                          ← 신규 패키지
│   ├── __init__.py
│   ├── server.py                   ← FastAPI 앱 팩토리
│   ├── routers/
│   │   ├── __init__.py
│   │   ├── data.py                 ← GET /api/results, /api/results/{id}
│   │   ├── config.py               ← GET/POST /api/thresholds, /api/datasets
│   │   ├── export.py               ← GET /api/export/{format}
│   │   └── stream.py               ← GET /api/stream (SSE 파일 감시)
│   ├── loader.py                   ← JSON 파일 파싱 → 통합 데이터 모델
│   ├── watcher.py                  ← watchdog 기반 파일 변경 감시
│   └── templates/
│       ├── dashboard.html.j2       ← 메인 대시보드 SPA
│       └── slides.html.j2          ← reveal.js 슬라이드
│
└── cli/
    └── main.py                     ← cmd_serve() 추가
```

### 3-1. 데이터 흐름

```
[results/*.json]
       │
       ▼
 loader.py  ──────► ResultSet (통합 데이터 모델)
       │
       ├──► /api/results          GET 전체 목록
       ├──► /api/results/{id}     GET 단일 파일
       ├──► /api/summary          GET 집계 지표
       ├──► /api/thresholds       GET/POST 임계값
       ├──► /api/stream           SSE 실시간 갱신
       └──► /api/export/{format}  HTML/CSV/JSON 내보내기
                │

         [browser SPA]
           Alpine.js
         ─────────────
          Chart.js (차트)
          Tabulator (테이블)

```

### Section I: 📚 Metrics Glossary (지표 사전)

**각 지표 카드:**
```
  ┌──────────────────────────────────────────────────────────┐
  │  Task Completion Rate (TCR)        Layer 1               │
  │  ──────────────────────────────────────────────────────  │
  │  📖 정의                                                  │
  │  전체 태스크 중 성공적으로 완료된 비율.                     │
  │  부분 성공은 가중치로 반영된다.                             │
  │                                                          │
  │  📐 계산 공식                                             │
  │  TCR = (완전성공 × 1.0 + 부분성공 × 0.5) / 전체 × 100    │
  │                                                          │
  │  🎯 업계 기준                                             │
  │  Excellent: ≥95%  Good: ≥90%  Fair: ≥80%  Poor: <80%    │
  │                                                          │
  │  💡 개선 가이드                                           │
  │  낮을 때: 에러 로그 분석 → Timeout, Tool Error 순으로 대응 │
  │  높을 때: Accuracy와 같이 모니터링 (속도/품질 트레이드오프) │
  └──────────────────────────────────────────────────────────┘
```

- 전체 지표 목록 (20+개) 알파벳/레이어별 정렬
- 검색 필터
- 각 지표에서 "이 지표로 이동" 버튼 → 해당 섹션 점프

## 10. 실시간 업데이트 (SSE)

```
  GET /api/stream

  이벤트 유형:
  ─────────────────────────────────────────────────────────
  data: {"event": "file_added",    "file": "perf_142301.json"}
  data: {"event": "file_updated",  "file": "perf_142301.json"}
  data: {"event": "file_removed",  "file": "perf_old.json"}
  data: {"event": "heartbeat",     "ts": 1710677183}

  브라우저 처리:
  ─────────────────────────────────────────────────────────
  const es = new EventSource('/api/stream');
  es.onmessage = (e) => {
    const msg = JSON.parse(e.data);
    if (msg.event === 'file_added') refreshFileList();
    // 토스트 알림: "새 평가 결과 수신됨"
  };
```

**토스트 알림 시스템:**
- 파일 추가/변경 시 우측 상단에 슬라이드인 알림
- "새 결과 있음 — 지금 갱신" 버튼
- 자동 새로고침 토글 (CI 모니터링 용도)
