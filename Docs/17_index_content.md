### ⚡ Zero Configuration

복잡한 설정 없이 즉시 시작할 수 있습니다. 단 몇 줄의 코드로 Agent 평가를 시작하세요.

### 📊 포괄적인 평가 지표 + 🔒 보안

Layer 1 Basic+Security(10개), Layer 2 Agentic+Security(6개), Layer 3 Advanced(9개) 총 25개의 평가 지표를 제공합니다. 보안 메트릭 5개 내장!

### 🎨 실시간 대시보드

Streamlit 기반의 직관적인 대시보드로 Agent 성능을 실시간으로 모니터링하세요.

### 🔍 완벽한 투명성

모든 평가 과정과 결과를 상세하게 추적하고 분석할 수 있습니다.

### 🌐 프레임워크 통합

CrewAI, LangChain, LangGraph, AutoGen 등 주요 AI 프레임워크와 완벽하게 통합됩니다.

### 🇰🇷 한국어 지원

한국어 RAG 시스템을 위한 특화된 평가 지표와 가이드를 제공합니다.

### 🔒 보안 우선

입력 검증(SQL Injection, Command Injection), 출력 보호(API키/비밀번호 유출 방지), 권한 관리, 공격 탐지(프롬프트 인젝션)를 자동으로 수행합니다.
