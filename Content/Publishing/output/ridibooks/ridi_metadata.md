## 책 소개 (리디북스 등록용 텍스트)

이 책에 대하여

AI 에이전트를 프로덕션에 배포하는 일은 기존 소프트웨어 배포와 근본적으로 다르다. 결정론적 함수는 동일한 입력에 항상 동일한 출력을 반환하지만, LLM 기반 AI 에이전트는 같은 질문에도 매번 다른 경로로 답에 도달하고, 때로는 환각(hallucination)으로 틀린 정보를 자신 있게 전달하며, 허가되지 않은 도구를 실행하거나 민감한 데이터를 출력에 포함시키기도 한다. 기존의 단위 테스트와 `assert` 방식만으로는 이 복잡성을 포착할 수 없다.

이 책은 그 간극을 메우기 위해 쓰였다. "에이전트가 잘 동작하는가"를 측정하는 것을 넘어, "이 에이전트는 배포해도 되는가"를 체계적으로 판정하는 새로운 평가 패러다임, Harness Engineering을 Python 코드로 직접 구현하는 방법을 실무 중심으로 다룬다. 오픈소스 SDK인 Agent-Evaluator를 활용하여 58개 지표와 7개 품질 게이트(Gate A–G)를 통해 AI 에이전트의 프로덕션 배포 준비도를 정밀하게 평가하는 전 과정을 26개 챕터에 걸쳐 안내한다.


이 책의 핵심 내용

이 책은 단순한 API 사용법 소개서가 아니다. AI 에이전트 품질 평가의 설계 철학부터 CI/CD 파이프라인 자동화까지, 실무에서 바로 적용할 수 있는 코드 예제와 함께 체계적인 지식을 전달한다.

Goal Achievement(목표 달성), Behavioral Integrity(행동 무결성), Reliability(신뢰성), Performance Contract(성능 계약), Security Boundary(보안 경계), Multi-Agent Coordination(다중 에이전트 협업), Observability(운영 관측성)의 7개 Gate로 구성된 Harness Engineering 프레임워크를 상세히 설명한다. 각 Gate는 코드로 선언 가능한 Config 데이터클래스와 연결되어, 품질 기준이 문서가 아닌 실행 가능한 코드로 고정된다.

실용성도 놓치지 않는다. LangChain, LangGraph, CrewAI, AutoGen 등 21개 주요 AI 프레임워크와의 통합 방법, LLM-as-Judge를 활용한 자동 채점, Arize Phoenix 기반 OpenTelemetry 관측 환경 구축, 그리고 GitHub Actions와 연동하는 CI/CD 품질 게이팅 구현까지 폭넓게 다룬다. 특히 기존 프로젝트에 평가 시스템을 침습 최소화 방식으로 이식하는 실전 가이드는 현업 Python 개발자와 AI 엔지니어에게 즉각적인 도움이 될 것이다.


이런 분께 권합니다

LLM 기반 애플리케이션을 개발하고 있으나 신뢰할 수 있는 품질 평가 체계 없이 배포를 결정해야 하는 상황에 처한 Python 개발자에게 적합하다. AI 에이전트의 정확도, 보안, 비용, 응답 지연을 하나의 통합된 시스템으로 모니터링하고 싶은 AI 엔지니어, 그리고 AI 서비스의 품질 기준을 CI/CD 파이프라인에 자동화하여 배포 신뢰성을 높이고자 하는 DevOps 엔지니어에게도 실질적인 참고서가 될 것이다. 이론보다 작동하는 코드를, 개념보다 현장에서 검증된 패턴을 선호하는 모든 실무자를 위한 책이다.
