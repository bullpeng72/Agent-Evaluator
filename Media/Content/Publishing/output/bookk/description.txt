[책 소개]

AI 에이전트는 결정론적 소프트웨어와 다르다. 동일한 질문에도 매번 다른 경로로 답에 도달하고, 환각(hallucination)으로 잘못된 정보를 자신 있게 전달하거나 허가되지 않은 도구를 실행하기도 한다. 기존의 `assert result == expected` 방식으로는 이 복잡성을 포착할 수 없다.

이 책은 LLM 기반 AI 에이전트를 프로덕션에 배포하기 전에 무엇을, 어떻게 평가해야 하는지를 다룬다. Harness Engineering이라는 관점에서 배포 기준을 코드로 선언하고, 7개 Harness Gate(A–G)로 에이전트의 배포 준비도를 종합 판정하는 실무 중심의 Python 품질 평가 가이드다. 오픈소스 SDK인 Agent-Evaluator를 활용해 58개 지표를 측정하고 CI/CD 파이프라인에 통합하는 전 과정을 실제 동작하는 예제 코드로 설명한다.


[이 책의 구성]

Part 1에서는 AI 에이전트 평가의 기초를 다진다. 정확도·할루시네이션·태스크 완료율 등 Layer 1 지표를 직접 측정하고, QuickEval로 5분 안에 첫 평가를 완성하는 방법을 안내한다.

Part 2는 Harness Engineering의 핵심 개념을 소개한다. Tracker, Config, Gate 세 역할이 어떻게 결합해 배포 가능 여부를 자동 판정하는지, Gate A–G의 전체 구조를 조감한다.

Part 3은 7개 Harness Gate를 Gate별로 심층 분석한다. 목표달성(A), 행동무결성(B), 신뢰성(C), 성능계약(D), 보안경계(E), 다중에이전트 협업(F), 운영관측성(G)까지 33개 Config의 선언 방법과 판정 기준을 구체적인 코드로 설명한다.

Part 4는 평가 데이터 설계, 데코레이터 활용, LangChain·LangGraph·CrewAI·AutoGen 등 주요 프레임워크 통합, 임계값 수립, 대시보드 시각화, 알림 시스템, CI/CD 품질 게이팅까지 실무 전반을 다룬다.

Part 5는 Arize Phoenix 기반 OTEL 분산 추적, DeepEval·Ragas 외부 평가 라이브러리 통합, 프로덕션 배포 전략과 종합 실무 파이프라인을 다룬다.

Part 6은 기존 프로젝트에 Agent-Evaluator를 이식하는 실전 가이드다. 실패 모드 카탈로그 작성부터 Gate 매핑 전략, 침습도 최소화 패턴, 골든 데이터셋 구축과 주간 품질 리뷰 자동화까지 현장 적용의 전 과정을 단계별로 안내한다.


[이런 분께 추천합니다]

LLM 기반 AI 에이전트를 개발하고 있으나 체계적인 품질 평가 방법을 아직 갖추지 못한 Python 개발자에게 권한다.

프로덕션 AI 시스템의 신뢰성과 보안 경계를 코드 수준에서 보장해야 하는 ML 엔지니어 및 AI 엔지니어에게 적합하다.

AI 에이전트의 배포 기준을 수립하고 CI/CD 파이프라인에 품질 게이트를 도입하려는 DevOps 엔지니어 및 QA 엔지니어에게 유용하다.

LangChain, LangGraph, CrewAI, AutoGen 등의 에이전트 프레임워크를 사용 중이며, 운영 환경에서의 할루시네이션·보안·성능 계약 관리에 실질적인 해법이 필요한 실무자에게 추천한다.


[저자 소개]

Sungwoo Kim은 AI Native 환경에서의 에이전트 평가 방법론을 연구하고, 오픈소스 AI 에이전트 품질 평가 SDK인 Agent-Evaluator를 설계·개발한 소프트웨어 엔지니어다. Harness Engineering 개념을 실무에 적용 가능한 코드 수준의 프레임워크로 구체화하는 작업을 지속하고 있다.
